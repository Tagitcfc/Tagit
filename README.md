# TagIt

**Human-Readable @Tag Payments on Stellar**

TagIt is a payment layer built on the Stellar network that allows users to send payments using a simple, human-readable **@Tag** instead of copying and sharing long Stellar wallet addresses.

Users can register a unique @Tag, associate it with their Stellar wallet address, search for another user's @Tag, and initiate a payment through the TagIt interface.

> **Network:** Stellar Testnet  
> **Status:** MVP  
> **Settlement Asset:** Stellar Testnet Assets  
> **Use Case:** Human-Readable Payments
